# Start here

1. Make a new empty GitHub repository (for example `square-one`).
2. Put everything from this folder into it, exactly as it is, and push.
   The 5 game files in `public/` must not be opened and re-saved by any editor.
3. Open the repository in Codex.
4. Paste the whole of `CODEX_PROMPT.md` as your first message.
5. When Codex finishes, follow the deploy steps in its final reply.

The full plan is in `AGENTS.md` (for Codex) and in the "Square One: backend architecture" doc (for the team).
